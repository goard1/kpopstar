# 10. 타이틀 화면 · 저장 슬롯 3개 · 대만판(繁體中文) 현지화

## 타이틀 화면 (UI/TitleScreen.cs)
- 앱을 켜면 Bootstrap이 게임보다 먼저 타이틀을 띄운다. 슬롯을 고르면 그때 `GameManager.Init`.
- 로고 카드: 한국어 「추억의 문방구」 / 대만판 「阿嬤的柑仔店」 + 부제.
- 슬롯 카드 3개: 날짜 · 동네 · 돈 · 평판 미리보기 → 「이어하기」 / 빈 슬롯은 「새 게임」.
  - 「지우기」는 두 번 눌러야 지운다 (첫 탭에 「지울게요」 + 경고). 그 슬롯의 앨범 사진도 함께 지운다.
  - 마지막에 한 슬롯은 금색 테두리로 표시 (PlayerPrefs `lastSlot`).
- 아래 언어 버튼: 한국어 / 繁體中文 (台灣). 누르면 바로 글꼴과 글이 바뀌고 화면을 새로 그린다.
- 게임 중 ⚙ 설정 → 「타이틀로」: 저장한 뒤 씬을 다시 불러온다 (언어는 타이틀에서 바꾼다).

## 저장 (Core/SaveSystem.cs)
- `SaveSystem.Slot` (1~3) → `save1.json` ~ `save3.json`.
- 예전 `save.json`이 있으면 1번 슬롯으로 옮긴다 (기존 폰 진행 그대로 이어짐).
- 앨범 사진: 1번은 `album/` (예전 그대로), 2·3번은 `album2/` · `album3/`.
- 언어·소리·배속·튜토리얼 완료는 슬롯과 상관없이 기기에 저장한다 (PlayerPrefs).

## 현지화 방식 (Core/Loc.cs)
게임 글은 코드에 한국어로 쓰고, **화면에 나갈 때**(SafeText.text) 지금 언어로 바꾼다. 부르는 곳마다 고치지 않아도 된다.

번역표 `Resources/Loc/zh-TW.txt` (한 줄에 `한국어⇒中文`):
- `{0}` `{1}` 이 있으면 **틀**: 끼운 값(상품 이름 등)도 다시 번역한다. `{0:yuan}`은 원 → 元.
- 단위(개·명·원·일·권·위·번·건·배·%) 바로 앞 빈칸은 숫자만 받는다 → 「캐릭터 카드 10개」를 이름과 개수로 바르게 나눈다.
- 순서: 그대로 맞는 줄 → 앞뒤 장식(★ · 따옴표 · 색/크기 태그)을 뗀 줄 → 긴 틀 → 장식 떼고 다시 → 줄마다 → 짧은 틀(`{0}, {1}` 등) → 낱말만 바꾸기.
- `~조각⇒中文`: 코드에서 이어 붙이는 조각 (예: `  ★완결`).
- 한국어 곧은따옴표 "…" 는 대만식 「…」로.
- 조사(을/를/이/가…)는 대만판에서 빼고, 낱말 뒤에 남은 조사도 지운다.
- 돈: 대만판은 **원 ÷ 10 = 元** (柑仔店 물가 느낌: 쫀드기 100원 → 王子麵 10元).
- 못 바꾼 글은 에디터에서 `Logs/loc-missing-zh.txt`에 쌓인다 (`» `로 시작하는 줄 = 화면에 나간 전체 문장).

도구:
- 메뉴 `문방구/번역할 문구 뽑기` → `Logs/loc-extract-ko.txt` (코드 속 한국어 1,200여 줄).
- 메뉴 `문방구/UI 스크린샷 찍기 (中文)` → `Logs/ui-shots-zh/*.png` + 못 바꾼 글 목록. (`0_title.png` = 타이틀)

글꼴: 대만판은 `Resources/Fonts/jf-openhuninn.ttf` (jf open 粉圓 2.1, SIL OFL — LICENSE 동봉). 둥글고 귀여운 번체 글꼴.
가게 간판: 한국어판은 「문방구」 블록 글자, 대만판은 TextMesh 「柑仔店」.

## 다음에 (아직 안 함)
- 영어판 등 다른 언어: `Lang`에 추가 + `Resources/Loc/<코드>.txt`.
- 대만판 전용 3D 모양은 4가지만 (王子麵 봉지·牛奶糖 상자·乖乖 초록 봉지·尪仔標 동그란 딱지). 나머지는 한국판 그대로.
- 사진 앨범 캡처 속 3D 간판은 찍은 때 언어 그대로 남는다.

## 대만판 상품 모양 · 명절 (10-2)
- `ProductVisuals.TaiwanShape`: 대만판일 때 王子麵(흰 봉지·빨간 띠·왕자 얼굴), 牛奶糖(노란 상자 + 종이 싼 사탕), 乖乖(초록 봉지·노란 로고), 尪仔標(그림 찍힌 동그란 딱지 묶음).
  게임을 시작할 때마다 상품 모양·아이콘 캐시를 비워서, 타이틀에서 언어를 바꾸면 모양도 바로 바뀐다.
- 명절 (두 언어 같은 날, 이름·이야기만 다름) — 4주마다 4주차 화요일에 돌아가며:

| 날 | 한국어판 | 대만판 | 효과 |
|---|---|---|---|
| 23일차, 107일차… | 어린이날 | 兒童節 | 손님 ×1.4, 장난감 ×1.8, 학용품 ×0.6, 만화방 ×1.4 |
| 51일차, 135일차… | 추석 | 中秋節 (烤肉) | 손님 ×1.1, 간식 ×2, 밖 놀이 ×1.5 |
| 79일차, 163일차… | 설날 (세뱃돈) | 春節 (紅包) | 손님 ×1.3, 1,000원 넘는 물건 ×2.2, 나머지 ×1.2 |

  전날 아침 달력에 "내일은 ○○!"이 뜨고, 그날 문을 열면 「오늘은 ○○! 아이들이 몰려와요」.

## 영어판 (10-3)
- 타이틀 언어 버튼 3개: 한국어 / 繁體中文 (台灣) / English. 번역표 `Resources/Loc/en.txt` (같은 형식 `한국어⇒English`).
- 대만판과 달리 **한국 동네 문방구를 그대로** 살린다: Jjondeugi · Ddakji · Apollo Straws, 철수 → Cheolsu, 돈은 **₩1,000** (원 그대로).
- 제목 「Grandma's Stationery Shop」. 아이들은 주인공을 **이름으로** 부른다 (〔CALL〕 → Jieun/Junho 또는 적은 이름).
- 번역값 `∅` = 일부러 비움 (영어에선 "명·개" 같은 단위를 안 붙이려고).
- 영어가 길어서 타이틀 제목·컷신 쪽지/편지 글은 칸에 맞게 글자 크기를 자동으로 줄인다.
- 도구: `문방구/UI 스크린샷 찍기 (English)` → `Logs/ui-shots-en`, 못 바꾼 글 `Logs/loc-missing-en.txt`.
