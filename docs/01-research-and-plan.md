# KPOP STAR (가제) — 시장 리서치 & 게임 기획서 v0.1

> 작성일: 2026-11-19 · 목표: 1인/소규모 개발로 Google Play 출시 → 광고+인앱결제로 수익화

---

## 0. 한 줄 요약 (결론)

**"머지-2(Merge-2) 퍼즐 + 아이돌 기획사 육성" 하이브리드 캐주얼 게임**을 원작 IP(오리지널 캐릭터/그룹)로 만들고,
K-팝 팬층이 두꺼우면서 광고 단가가 싼 **동남아(필리핀·인도네시아·태국)에서 소프트런칭** → 지표가 나오면 글로벌 확장.

이유 3가지:
1. **머지-2는 2026년 캐주얼에서 가장 빨리 크는 장르** (H1 2026 매출 약 $1.3B, 전년 대비 +74%).
2. **하이브리드 캐주얼은 2025~2026년 유일하게 매출이 성장한 세그먼트** (H1 2026 +23%). 하이퍼캐주얼은 하락세(-18%).
3. **K-팝은 『케이팝 데몬 헌터스』 이후 글로벌 메인스트림** ("Golden" 아카데미 주제가상 후보·시상식 라이브 공연). 그런데 기존 아이돌 게임은 대부분 오래된 텍스트형 경영 시뮬(Monthly Idol, K-Pop Academy 등) → **"세련된 머지 퍼즐 + 아이돌" 조합은 비어 있는 자리**.

### 1-3. K-팝 게임 경쟁 현황
| 게임 | 유형 | 약점 (우리의 기회) |
|---|---|---|
| Monthly Idol | 기획사 경영 시뮬 (장수작) | 텍스트·수치 위주, 캐주얼 유저 진입 장벽 |
| K-Pop Academy (HyperBeard) | 아이들 경영 | 깊이 얕음, 퍼즐 손맛 없음 |
| KPop Idol Queens Production | 경영 시뮬 | 오래됨 |
| K-pop Idol Stories: Road to Debut (2026.7, PC) | 매니저 시뮬+미니게임 | PC 중심 → 모바일 공백 |
| Idol Company | 셀럽 게임 (美 iOS 주 $25K 수준 매출) | **아이돌 테마로도 과금이 된다는 증거** |
| 데몬헌터스 짝퉁 게임들 (피아노타일, 샌드박스, 머지 등) | 비공식 팬게임, 10만~50만 DL | 수요는 있다는 증거 / **IP 침해라 따라하면 안 됨** |

**결론:** 수요는 확인됨(짝퉁도 수십만 DL), 공급은 "낡은 경영 시뮬" 또는 "무단 IP 게임"뿐. → **합법적인 오리지널 IP + 트렌디한 머지 장르**로 들어갈 틈이 있음.

### 1-4. 수익화 모델 벤치마크 (참고용, 업체 블로그 기반이라 편차 큼)
| 광고 형식 | eCPM (Tier-1: 미·영·일·독) | eCPM (동남아 등) |
|---|---|---|
| 보상형 동영상 | 약 $8~18 (일부 $10~50) | 약 $1~8 |
| 전면 광고 | 약 $5~20 | 더 낮음 |
| 배너 | 약 $0.1~2 | 매우 낮음 |

- 하이브리드 캐주얼 정석: **무과금 유저 → 보상형 광고**, **과금 유저 → 광고제거 + 소액 패키지 + 시즌패스**.
- 주의: 보상형 광고 보상이 너무 크면 결제 동기가 사라짐.
- 현실: **인디 게임 중앙값 수익은 매우 낮다**. 수익은 소수 히트작에 집중됨 → 빠르게 만들고, 지표 보고, 안 되면 빨리 접거나 피벗하는 전략 필요.

## 2. 게임 컨셉

### 2-1. 개요
- **가제:** KPOP STAR: Idol Merge (한글: 케이팝 스타: 아이돌 머지) — 상표 검색 후 확정
- **장르:** 머지-2 퍼즐 + 아이돌 기획사 육성 (하이브리드 캐주얼)
- **타깃:** 13~34세, K-팝/애니 팬, 여성 비중 높음 (머지 장르 주 이용층과 일치)
- **플랫폼:** Android 우선 (세로 화면, 오프라인 플레이 가능), 이후 iOS
- **판타지:** "망해가는 작은 기획사를 물려받아, 연습생을 데뷔시키고 월드투어 그룹으로 키운다"

### 2-2. 코어 루프
```
[머지 보드]  아이템 합치기 (마이크 → 헤드셋 마이크 → 골드 스탠드 마이크 …)
     ↓
[주문 완료]  멤버/스태프의 요청 달성 ("보컬 연습용 헤드셋 + 생수 2개")
     ↓
[보상]       코인 · 팬 수 · 경험치 · 스토리 진행
     ↓
[메타]       멤버 능력치 트레이닝 / 연습실·숙소·무대 꾸미기 / 데뷔·컴백 무대
     ↓
[다음 챕터]  새 아이템 체인 · 새 멤버 · 새 장소(소극장 → 체조경기장 → 월드투어)
```

### 2-3. 아이템 체인 예시 (각 6~10단계)
| 체인 | 예시 단계 |
|---|---|
| 보컬 | 목캔디 → 생수 → 마이크 → 헤드셋 마이크 → 인이어 → 골드 마이크 |
| 댄스 | 운동화 → 댄스화 → 무릎보호대 → 안무 노트 → 안무 영상 → 시그니처 안무 |
| 패션 | 실 → 원단 → 티셔츠 → 무대 의상 → 디자이너 의상 → 시상식 드레스/수트 |
| 굿즈 | 스티커 → 포토카드 → 응원봉 → 앨범 → 한정판 앨범 |
| 미디어 | 셀카 → 숏폼 → 뮤비 티저 → 뮤직비디오 → 음악방송 1위 트로피 |

### 2-4. 메타 시스템
- **그룹/멤버:** 오리지널 5인조 걸그룹 + 5인조 보이그룹 (2번째 그룹은 업데이트로). 멤버별 포지션(보컬/댄스/랩/비주얼)과 스토리.
- **데뷔 & 컴백 이벤트:** 챕터 끝마다 "무대" 연출(간단한 2D 애니메이션 + 터치 리듬 미니게임 30초) → 팬 수 폭발.
- **꾸미기:** 연습실·숙소·무대 인테리어 (머지 장르 표준 메타, 리텐션에 효과적).
- **의상 컬렉션:** 멤버별 의상 세트 (과금·이벤트 보상 핵심 상품).
- **라이브 이벤트 (리텐션):** 주간 "컴백 시즌" 미니 보드 이벤트, 시즌 패스, 생일 이벤트(멤버별).

### 2-5. 차별화 포인트
1. **"내가 만든 그룹" 감정이입** — 그룹명·팬덤명 직접 작명, 데뷔 무대 연출.
2. **숏폼 친화 연출** — 데뷔 무대/챌린지 장면을 그대로 캡처·공유 가능 (틱톡/쇼츠 바이럴 = 무료 마케팅).
3. **팬덤 문화 재현** — 응원법, 포토카드 수집, 음방 1위 등 K-팝 팬만 아는 디테일.

## 3. 수익화 설계

| 수익원 | 내용 | 가격(예시) |
|---|---|---|
| 보상형 광고 | 에너지 충전, 보상 2배, 생성기 즉시 충전, 막힌 아이템 해제 | 하루 5~10회 상한 |
| 전면 광고 | 챕터 클리어 후 등 자연스러운 지점만, 초반 3일은 없음 | — |
| 광고 제거 | 전면 광고 영구 제거 (보상형은 유지 or 자동 지급) | ₩4,900 |
| 스타터 팩 | 첫 구매 유도 (에너지+다이아+한정 의상) | ₩1,200~2,500 |
| 시즌 패스 (컴백 패스) | 4주 단위, 무료/유료 트랙 | ₩6,500~9,900 |
| 의상/꾸미기 | 직접 판매 (확률형 아님) | ₩2,500~12,000 |
| 다이아 패키지 | 에너지·부스터 구매용 | ₩1,200~59,000 |

**설계 원칙**
- **확률형 아이템(가챠)은 초기엔 넣지 않는다.** 한국은 2024.3부터 유료 확률형 아이템 확률 공개가 법적 의무 → 1인 개발자에겐 관리 부담. 의상은 직접 판매.
- Google Play 수수료: 연 매출 첫 $1M까지 15%.
- 광고 미디에이션: **AdMob + (AppLovin MAX 또는 Unity LevelPlay)**.

|---|---|---|---|---|
| 실패 | 300 | $2 | $1 | 약 $90 (≈12만원) |

## 4. 개발 계획

### 4-1. 기술 스택 (추천)
| 항목 | 선택 | 이유 |
|---|---|---|
| 엔진 | **Unity 6 (2D)** | 광고/결제/분석 SDK 생태계 가장 풍부, 머지 게임 레퍼런스 많음 |
| (대안) | Godot 4 | 무료·가벼움, 단 광고 SDK 연동이 번거로움 |
| 광고 | Google AdMob (+ 미디에이션) | 표준 |
| 결제 | Google Play Billing (Unity IAP) | 표준 |
| 분석 | Firebase Analytics + Crashlytics | 무료, 리텐션 퍼널 측정 |
| 원격 설정 | Firebase Remote Config | 업데이트 없이 밸런스/광고 빈도 조정, A/B 테스트 |
| 저장 | 로컬 저장 + (선택) 클라우드 세이브 | 초기엔 서버 없이 |
| 아트 | 치비(SD) 2D 일러스트, 아이템 아이콘 | AI 생성 시 상업 이용 라이선스 확인 필수 |
| 음악 | 오리지널 곡 의뢰 or 상업용 라이선스 음원 | **실제 K-팝 곡 절대 사용 금지** |

### 4-2. 마일스톤 (1인 + Claude 기준, 약 3개월)

### 4-3. MVP 범위 (이것만 있으면 출시 가능)
- [ ] 머지 보드 (드래그·합치기·생성기·에너지)
- [ ] 주문 시스템 + 보상
- [ ] 챕터 1~5 (약 1~2주 플레이 분량)
- [ ] 걸그룹 1팀 (5인) + 스토리 대화
- [ ] 데뷔 무대 연출 1종
- [ ] 연습실 꾸미기
- [ ] 보상형 광고 / 광고 제거 IAP / 스타터 팩
- [ ] 로컬 세이브, 오프라인 에너지 회복
- [ ] 한국어 + 영어 (+ 인니어/태국어/스페인어는 소프트런칭 지표 보고)

**MVP에서 뺄 것:** 멀티플레이, 길드, 가챠, 서버, 보이그룹(→ 첫 대형 업데이트 콘텐츠로).

## 6. 마케팅 (저예산)

1. **숏폼 우선:** 게임 속 데뷔 무대·의상 변신 장면을 틱톡/유튜브 쇼츠/릴스에 주 3~5회. "내 최애 그룹 만들기" 포맷.
2. **팬덤 커뮤니티:** Reddit r/kpop·r/kpophelp(규칙 확인), X(트위터) K-팝 계정, 디스코드 서버 개설 → 멤버 인기투표, 다음 멤버 디자인 투표.
3. **ASO:** 제목/설명에 "kpop, idol, merge, dress up, agency" 키워드. 스크린샷 첫 장은 캐릭터 얼굴.
4. **사전등록:** Google Play 사전등록 기능으로 출시 전 대기 유저 확보.
5. **유료 광고는 지표 확인 후:** D1 35%+, D7 12%+ 정도 나오면 소액(일 $10~20)으로 동남아 UA 테스트.
