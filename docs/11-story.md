# 11. 이야기 — 인트로 · 컷신 · 엔딩

## 줄거리 한 줄
할아버지가 몰래 마련해 둔 골목 가게를 할머니가 열고, 할아버지 수첩의 바람을 하나씩 이뤄 가다가, 마지막에 할아버지의 편지를 연다.

(이미 있던 조각에 맞춤: 앨범 마지막 장 「할아버지의 편지」, 어른이 된 철수·영희·민수, 이사, 숨은 만화 「할머니의 문방구」)

## 장 구성
| 장 | 언제 | 장면 |
|---|---|---|
| 프롤로그 · 파란 셔터 | 새 게임 시작 (1일차 아침, 튜토리얼 전) | 할아버지가 떠나고 한 달 → 서랍 속 열쇠·쪽지 「학교 앞 골목, 파란 셔터」 → 셔터가 올라가며 문방구 → 젊은 시절 사진 ("아이들 웃음소리 나는 가게") → 철수 "여기 가게 해요?" → 3D 가게, 계산대 할머니 클로즈업 |
| 1장 · 할아버지의 수첩 | 첫 증축 | 선반 뒤에서 수첩: 이름 불러 주기 · 평상 · 2층 만화책 (= 다음 목표 힌트) |
| 2장 · 이사 가는 날 | 첫 이사 | 노을 골목, 손 흔드는 아이들·이삿짐 트럭 → 수첩 둘째 장 "처음 골목은 잊지 말 것" |
| 3장 · 큰길가 문방구 | 두 번째 이사 | 큰 간판 → 수첩 마지막 장 "다 하면 편지를 열어 볼 것" |
| 마지막 장 · 할아버지의 편지 | 마지막 동네 증축을 다 지음 | 저녁 가게 → 어른이 된 철수(체육 선생님)·영희(디자이너)·민수(장난감 회사) → 편지 전문 → 사진 → "내일도 셔터 올려야지" → 크레딧 → 계속 장사 |

- 본 장은 저장(`TownSave.story`)에 남아 다시 안 뜬다. 예전 세이브는 켤 때 이미 지난 장을 순서대로 한 번 보여 준다 (프롤로그 빼고).
- 동네 → 앨범 위 「이야기 다시 보기」에서 본 장을 다시 볼 수 있다.
- 화면: 위 삽화 카드 + 아래 말 카드(이름표 색 = 인물), 글자는 한 글자씩, 탭 = 다 보이기/다음, 오른쪽 위 「건너뛰기」.
  보는 동안 다른 UI는 숨긴다. 삽화는 그림 파일 없이 UI 도형으로 그린다 (둥근 머리 꼬마·할머니는 3D와 같은 초록 옷).

## 대만판
번역표에서 阿嬤 · 阿公 · 國小對面巷口 · 藍色鐵捲門 · 柑仔店으로. 편지 서명 「— 영감이」 → 「——妳的老伴」.
크레딧 제목도 「阿嬤的柑仔店」.
