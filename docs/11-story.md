# 11. 이야기 — 인트로 · 컷신 · 엔딩

## 줄거리 한 줄
할아버지가 돌아가시고 며칠 뒤 할머니도 따라 떠나셨다. 손주는 할머니 서랍에서 열쇠와 쪽지를 찾는다.
할아버지가 할머니를 위해 몰래 마련해 둔 골목 문방구가 있었고, 할머니는 끝내 그 문을 열지 못했다.
손주가 대신 셔터를 올리고, 할아버지 수첩의 바람을 하나씩 이뤄 가다가, 마지막에 편지와 할머니가 덧붙인 글을 읽는다.

## 주인공 = 손주 (`Core/Hero.cs`)
- 새 게임 → 타이틀에서 **손녀/손자**를 고르고 이름을 적는다 (비우면 지은/준호, 대만판 小雯/阿傑). 슬롯마다 저장.
- 계산대 의자에는 노란 앞치마를 두르고 만화책을 읽는 손주 (손녀: 묶은 머리 + 리본, 손자: 짧은 머리).
- 아이들은 주인공을 **누나/형** (여자아이는 **언니/오빠**), 대만판은 **姊姊/哥哥**라고 부른다.
- 글 속 표시: `〔NAME〕` 이름, `〔CALL〕` 아이들 호칭, `〔CALLG〕` 여자아이가 부를 때. SafeText가 화면에 낼 때 바꾼다.
  표시 바로 뒤에 조사를 붙이지 않는다 (누나는/형은). 〔CALLG〕는 언니/오빠라 "가"까지 괜찮다.
- 할머니가 남긴 것: 할머니 작업대·할머니표 특제(레시피), **할머니의 비법**(예전 할머니 스킬, 할머니 노트에서 배움), 만화 「할머니의 문방구」.

## 장 구성
| 장 | 언제 | 장면 |
|---|---|---|
| 프롤로그 · 파란 셔터 | 새 게임 시작 (튜토리얼 전) | 할아버지, 며칠 뒤 할머니도 → 할머니 서랍 속 열쇠·쪽지 「할미 대신 문 좀 열어 줄래? — 학교 앞 골목, 파란 셔터」 → 셔터가 올라가며 문방구 → 두 분의 젊은 시절 사진 → 철수 "누나! 여기 가게 해요?" → 계산대의 주인공 |
| 1장 · 할아버지의 수첩 | 첫 증축 | 수첩 첫 장: 이름 불러 주기 · 평상 · 2층 만화책 (다음 목표 힌트) |
| 2장 · 이사 가는 날 | 첫 이사 | 노을 골목 아이들 배웅 → 수첩 둘째 장 "처음 골목은 잊지 말 것" |
| 3장 · 큰길가 문방구 | 두 번째 이사 | 수첩 마지막 장 "다 하면 편지를 열어 볼 것" |
| 마지막 장 · 할아버지의 편지 | 마지막 동네 증축 완료 | 어른이 된 철수·영희·민수 → 할아버지가 할머니께 쓴 편지 → 뒷면에 할머니 글씨 "할미는 끝내 이 문을 못 열었지만 네가 대신 열어 줘서 고맙다…" → "할머니, 할아버지… 보고 계시죠?" → 크레딧 → 계속 장사 |

- 본 장은 `TownSave.story`에 남아 다시 안 뜬다. 예전 세이브는 켤 때 이미 지난 장을 순서대로 한 번 (프롤로그 빼고).
  예전 세이브는 주인공 정보가 없어 손녀 「지은」으로 시작한다.
- 동네 → 앨범 위 「이야기 다시 보기」.
- 화면: 위 삽화 + 아래 말 카드, 글자 한 글자씩, 탭 = 다 보이기/다음, 「건너뛰기」. 보는 동안 다른 UI는 숨김.
