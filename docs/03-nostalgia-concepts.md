## 1. 리서치 요약

### 1-1. 추억(노스탤지어) 트렌드
- **한국:** 레트로 장난감·문구가 "어릴 때 돈 없어 못 샀던 것"을 사는 경제력 있는 어른의 소비로 확산. 창신동 문구·완구 거리, 동묘 벼룩시장에 20대 커플 증가. 인라인스케이트 등 2000년대 초등학생 놀이를 2030이 다시 함. '토이 스토리' 영향으로 지구색연필 등 추억템 인기.
- **촉감·ASMR 위안 소비:** 말랑이(스퀴시), 왁스볼 등 "손안의 위로" 트렌드 (Korea Herald, Korea Times 2026.6~7).
- **글로벌:** 레트로 게임 시장 2026년 약 $4.2B, 연 10% 성장(단일 집계 출처). Y2K·Frutiger Aero 감성이 Z세대 정체성 표현으로 소비됨. 다마고치 30주년 전시·투어, 성인 팬 문화 성장.
- **일본에도 같은 원형이 있음:** 駄菓子屋(다가시야, 동네 과자·장난감 가게) → 한국 문방구와 같은 추억 코드라 **일본 시장 확장이 자연스러움**.

### 1-2. 장르 트렌드 (상점/직업 시뮬레이터)
- Steam: Supermarket Simulator가 장르를 정의, 이후 Megastore Simulator, Supermarket Chaos, Wild West/Cart by Cart/Multiplayer Supermarket Simulator 등 변종 쏟아짐 → **"익숙한 직업 + 특이한 소재" 조합이 먹힘**.
- 모바일: 카드샵 시뮬레이터류가 50만+ DL → **팩 개봉 + 수집 + 진열**의 손맛이 모바일에서도 통함.

### 1-3. 참고 사례: Retro Bowl
- 레트로 픽셀 미식축구, 1인 중심 소규모 스튜디오.
- 광고비 0원, 틱톡 → 미국 iOS 무료 1위, 모바일 1,700만+ DL(개발사 주장).
- 교훈: **레트로 감성 + 단순한 조작 + 공유하고 싶은 순간**이면 광고비 없이 큼. 단, 다운로드가 줄면 매출도 바로 줄었음 → **장기 리텐션 장치(스토리·수집·시대 진행) 필요**.

## 2. 메인 컨셉 상세: 「추억의 문방구」

### 2-1. 개요
| 항목 | 내용 |
|---|---|
| 장르 | 상점 경영 시뮬레이터 + 수집 + 미니게임 (+ 감성 스토리) |
| 시점 | 고정 쿼터뷰 3D 로우폴리 (모바일 터치에 맞게 1인칭 대신) |
| 타깃 | 1차: 한국 25~45세 (90~00년대 초등학생) / 2차: 일본(다가시야)·동남아·북미 Y2K 세대 |
| 플랫폼 | Android → Steam(PC) → iOS |
| 플레이 단위 | 하루 1판 = 3~5분 (등교 전 → 하교 러시 → 방과 후 → 정산) |

### 2-2. 하루 루프
```
[아침]   도매상에서 매입 — 이번 주 유행 예측 (요요 붐? 딱지 붐? 스티커 붐?)
   ↓
[진열]   진열대·뽑기판·오락기 배치, 가격 책정
   ↓
[하교 러시]  꼬마 손님 응대 — 계산, 동전 거스름돈 (짤랑 ASMR), 외상 장부(!)
   ↓
[방과 후]  오락기·뽑기 수익 회수, 딱지치기 대회, 단골 이벤트
   ↓
[정산]   매출 확인 → 가게 확장·인테리어·새 상품 해금
```

### 2-3. 핵심 시스템
1. **유행(붐) 시스템** — 매주 랜덤으로 유행 아이템이 바뀜. 미리 사재기하면 대박, 유행 끝나면 재고 폭탄. *실제 그 시절 '붐'을 게임화* (전략성의 핵심).
2. **시대 진행 (챕터)** — 1995 → 2000 → 2005 → 2010 → 스마트폰 시대. 시대마다 상품·손님·가게 분위기 변화. 마지막엔 문방구 위기와 선택형 엔딩.
3. **단골 손님 성장 스토리** — 초등학생 단골이 중학생→고등학생→어른이 되어 **자기 아이를 데리고 다시 옴**. (숏폼에서 우는 댓글 나오는 장면)
4. **수집 도감** — 스티커·카드 팩을 직접 뜯는 손맛 (오리지널 일러스트), 딱지·구슬 컬렉션.
5. **미니게임** — 딱지치기, 구슬치기, 번호 뽑기판, 문방구 앞 오락기(오리지널 레트로 미니게임 2~3종).
6. **촉감·ASMR** — 포장 뜯기, 동전, 말랑이 주무르기, 셔터 올리는 소리. 만족감 영상 = 마케팅 소재.
7. **꾸미기** — 간판, 진열대, 평상, 가게 앞 오락기 라인업.

### 2-4. 수익 모델
| 플랫폼 | 모델 | 내용 |
|---|---|---|
| Android | 무료 + 가벼운 수익화 | 보상형 광고(손님 몰이, 즉시 입고, 하루 보너스) / 광고 제거 ₩3,900 / 가게 확장·시대 DLC·인테리어 팩 ₩1,200~6,500 |
| Steam | 유료 | $9.99~14.99 일시불 (상점 시뮬 장르 표준) |

- **유료 확률형 아이템은 넣지 않음.** 게임 속 뽑기판·카드 팩은 **게임 내 화폐로만** 구매 (한국 확률형 아이템 표시 의무 리스크 회피).
- 출시 후 업데이트 = "새 시대 챕터", "일본 다가시야 확장" 같은 콘텐츠 DLC.

### 2-5. IP·저작권 주의
- 실제 제품 **브랜드명·로고·캐릭터 금지** (특정 과자 상표, 다마고치·포켓몬·유희왕·탑블레이드 등). **"딱지, 구슬, 쫀드기류 과자, 디지털 펫 장난감"처럼 일반 명사·오리지널 디자인으로**.
- 오락기 미니게임은 **기존 명작을 따라 만들지 않고 오리지널 규칙**으로.
- 시대 배경 음악·광고 패러디도 오리지널로.

## 4. 개발 로드맵 (A 기준)

| 기간 | 목표 | 산출물 |
|---|---|---|
| 1~2주 | **재미 검증** | Unity 그레이박스: 진열 → 손님 → 계산 → 정산 1일 루프. 유행 시스템 시트 |
| 3~4주 | 감성 검증 | 로우폴리 가게 1개, 상품 20종, ASMR 사운드, 단골 1명 이벤트. **숏폼 3개 올려 반응 테스트** |
| 5~12주 | 버티컬 슬라이스 | 1995~2000 챕터, 미니게임 2종, 수집 도감, 꾸미기. Steam 페이지 오픈(위시리스트 수집) |
| 10주~ | Google Play 비공개 테스트 | 12명×14일 |
| 4~6개월 | Android 출시 | 이후 Steam 출시, 일본어 현지화 |

**아트 전략:** Unity 에셋 스토어 로우폴리 팩 + 상품 아이콘은 직접/외주. 사람 캐릭터는 단순한 치비 스타일로 부담 줄이기.

**마케팅:**
- "90년대생만 아는 문방구 아이템" 숏폼 시리즈 (개발 초기부터).
- 단골 손님 성장 장면, 셔터 내리는 마지막 날 장면 = 감성 클립.
- 추억 커뮤니티(더쿠, 인스티즈, 에펨코리아 등의 추억 게시판), 일본 X(트위터)의 駄菓子屋 해시태그.
