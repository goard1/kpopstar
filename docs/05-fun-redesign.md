# 「추억의 문방구」 재미 재설계 v0.1

> 작성일: 2026-11-21 · 배경: 코어 루프·업그레이드·돌발 사건까지 넣었는데 "한두 판 하면 지루하다"
> 결정: **A. 아이 마음 읽기(상담 손님)** 를 핵심 재미로, **D. 생존 압박(월세·평판·대형 할인점)** 을 긴장감으로, **B. 카드팩 뜯기·수집** 은 나중에 양념으로.

---

## 1. 왜 재미없나 (진단)

| 문제 | 지금 상태 |
|---|---|
| 핵심 동작에 판단이 없다 | 손님이 오면 말풍선 탭. 돌발 사건도 결국 탭. 잘함/못함의 차이가 거의 없음 |
| 결정이 얕다 | 싸게 사서 다 채우면 끝. 유행 말고는 고민거리가 없고 돈이 줄 위험도 거의 없음 |
| 잃을 게 없다 | 월세·경쟁자·기한이 없어서 긴장이 안 생김 |
| 추억이 장식에 그친다 | 쫀드기·딱지가 "가격 다른 아이템"일 뿐, 그 물건이라서 생기는 재미가 없음 |

→ 기능을 더 얹어도 "하루 한 판이 같은 느낌"이 근본 문제. **핵심 동작 자체를 바꾼다.**

## 2. 새 핵심 재미: 아이 마음 읽기 (상담 손님)

참고: *Good Pizza, Great Pizza* — 손님마다 애매한 주문을 해석해서 맞춰 주는 재미.

### 2-1. 흐름
1. 상담 손님은 매대로 가지 않고 **계산대로 바로 와서** 말을 건다.
   예) "500원 있는데 친구랑 같이 놀 수 있는 거요", "짝꿍 생일이에요! 선물 추천해 주세요"
2. 말풍선을 탭하면 **고르기 창**이 열린다 (게임 시간 정지, 차분한 퍼즐).
   매대에 진열된 상품이 아이콘 카드로 뜨고, **예산을 넘는 건 흐리게**.
3. 하나를 골라 주면 판정:

| 판정 | 조건 | 결과 |
|---|---|---|
| **딱 맞아요!** | 요청의 핵심 특징 + 덤 특징까지 맞음 | 값 + 팁(30~50%) + 평판 +2, 기뻐하는 대사 |
| **괜찮아요** | 핵심 특징만 맞음 | 값만, 평판 그대로 |
| **이건 아닌데…** | 핵심 특징 없음 | 반반 확률로 "그래도 살게요"(값, 평판 -1) / 그냥 감(평판 -2) |
| **잘 모르겠어요** (미안, 없어) | 맞는 게 진열 안 됨 | 그냥 감, 평판 -1 |

4. 셀프 손님(지금처럼 직접 집어 오는 아이)도 그대로 있다. 상담 손님 비율은 1일차 30% → 날마다 +5% → 최대 60%.

### 2-2. 상품 특징 (태그)
각 상품에 2~3개 특징. **처음엔 특징이 안 보이고, 상담으로 한 번 팔아 보면 그 상품 특징이 드러난다** (지식이 쌓이는 재미, "할머니의 경험").
상품 설명(blurb)은 항상 보여서 힌트가 된다.

| 상품 | 값 | 특징 |
|---|---|---|
| 쫀드기 | 100 | 간식, 오래, 싸다 |
| 아폴로 | 100 | 간식, 달콤, 싸다 |
| 딱지 | 200 | 놀이, 친구랑, 멋짐 |
| 구슬 | 200 | 놀이, 친구랑, 수집 |
| 지우개 | 100 | 학용품, 귀여움, 수집 |
| 스티커 | 200 | 귀여움, 수집, 선물 |
| 종이인형 | 300 | 귀여움, 혼자, 선물 |
| 미니카 | 1000 | 멋짐, 선물, 기술 |
| 맥주사탕 | 50 | 간식, 장난, 싸다 |
| 연필 | 100 | 학용품, 선물 |
| 탱탱볼 | 200 | 놀이, 밖, 친구랑 |
| 요요 | 500 | 기술, 멋짐, 놀이 |
| 쌀대롱 | 100 | 간식, 오래, 친구랑 |

(번호 뽑기는 뽑기판 전용이라 상담 대상에서 뺀다.)

### 2-3. 요청 예시 (프로토타입 18종)
- "500원 있는데 친구랑 같이 놀 수 있는 거요" — 핵심: 친구랑 / 덤: 놀이 / 예산 500
- "짝꿍 생일이에요! 선물할 거 추천해 주세요" — 선물 / 귀여움 / 1000
- "학원 가기 전에 배고파요… 300원 있어요" — 간식 / 오래 / 300
- "100원밖에 없어요. 맛있는 거요" — 간식 / 달콤 / 100
- "형한테 이길 수 있는 거요!" — 멋짐 / 기술 / 1000
- "운동장에서 놀 거요!" — 밖 / 친구랑 / 500
- "친구 놀래킬 장난감이요, 히히" — 장난 / 촉감 / 500
- "비 와서 집에만 있어요. 혼자 놀 거요" — 혼자 / 귀여움 / 1000
- "모으는 거 좋아해요. 뭐 새로운 거 없어요?" — 수집 / 운 / 300
- "말랑말랑한 거요!" — 촉감 / 귀여움 / 300 … 등

요청은 **해금된 상품 중 맞는 게 하나라도 있는 것만** 나온다. 하지만 진열은 플레이어 몫 → "다양하게 진열해 둬야 상담을 잘 받는다"는 매입 판단이 생긴다.

### 2-4. 평판 (동네 소문)
- 0~100, 시작 50. 상담 결과로 오르내림.
- 평판이 높을수록 손님이 많이 오고(×0.85~×1.15), 나중엔 단골·특별 의뢰가 열린다.
- 정산 화면에 "딱 맞음 / 괜찮음 / 아님" 횟수와 평판 변화 표시.

## 3. 압박 (D) — 프로토타입 검증 뒤에 붙임

- **주간 월세**: 7일마다 월세(1주차 8,000원부터 점점↑). 못 내면 빚 → 3번이면 가게 위기 이벤트.
- **대형 문구 할인점** (3주차~): 학용품·간식처럼 "그냥 사는 물건"은 할인점으로 빠져나감. 대신 **상담(마음 읽기)은 할인점이 못 하는 것** → 평판이 높을수록 버틴다. 테마와 시스템이 같은 이야기를 함.

## 4. 기존 시스템과의 관계

| 시스템 | 처리 |
|---|---|
| 업그레이드 상점 | 유지. 나중에 "상담" 관련 업그레이드 추가 (예: 아이 마음 수첩 = 특징 미리 보기) |
| 돌발 사건 | 유지 (상담 손님과 섞여 하루의 변주) |
| 뽑기판 | 유지 |
| 유행 | 유지. 유행 상품을 원하는 상담 요청도 추가 예정 |
| 알바생 | 셀프 손님만 자동 계산 (상담은 주인 몫) |

## 5. 프로토타입 범위와 검증

**만들 것 (하루 분량)**
- 상품 특징 표 + 요청 18종 + 상담 손님 흐름 + 고르기 창 + 판정·반응·팁
- 특징 발견(상담으로 판 상품의 특징 공개) + 평판 + 정산 표시

**검증 질문** — 폰으로 2~3일 해 보고:
1. 상담 손님이 오면 "뭘 줄까?" 하고 **잠깐이라도 고민**되는가?
2. "딱 맞아요!"가 **기분 좋은가**? (팁·대사·연출)
3. 상담을 잘하려고 **진열을 다양하게 바꾸고 싶어지는가**?

셋 다 "예"면 이 방향으로 확장 (압박·카드팩). 아니면 B(카드팩)나 C(손놀림)로 갈아탐.
