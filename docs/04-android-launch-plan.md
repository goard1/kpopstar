# 「추억의 문방구」 Android 출시 계획 v0.1

> 작성일: 2026-11-20 · 결정 사항: **Unity / Android(Google Play) 단독 출시 우선**, Steam·iOS는 나중에

---

## 1. 바뀐 점 (Steam 병행안 대비)

| 항목 | 이전 안 | Android 단독 안 |
|---|---|---|
| 수요 검증 | Steam 위시리스트 | **숏폼 반응 + Google Play 비공개 테스트 지표** |
| 수익 모델 | Steam 유료 + 모바일 F2P | **F2P (보상형 광고 + IAP)** 하나로 |
| 화면 | PC 가로 | **세로 화면, 한 손 조작** |
| 세션 | 자유 | **하루 1판 = 3~5분** (출퇴근·쉬는 시간 플레이) |
| 글로벌 | Steam이 해외 담당 | **Google Play 국가 선택으로 단계적 확장** |

---

## 2. 출시 국가 단계

| 단계 | 국가 | 언어 | 목적 |
|---|---|---|---|
| 비공개 테스트 | 지인·커뮤니티 12명+ (넉넉히 20명) | 한국어 | 버그·튜토리얼 이탈 확인 (필수 14일) |
| 1차 출시 | **한국** | 한국어 | 추억 직격 시장, 숏폼 바이럴 엔진 |
| 1차 동시 (선택) | 필리핀·말레이시아·싱가포르 | 영어 | 영어권 반응 저비용 체크 |
| 2차 | 일본, 대만 | 일본어, 번체 | 다가시야·문구점 추억 공유권 |
| 3차 | 미국·영국·캐나다·호주 + 남미 | 영어, 스페인어, 포르투갈어 | 광고 단가 높은 시장 |

> Google Play Console에서 국가별로 켜고 끌 수 있어서, 한 번 만든 앱을 그대로 단계 확장하면 됨.

## 3. 수익화 (F2P)

| 상품 | 내용 | 가격(예시) |
|---|---|---|
| 보상형 광고 | 손님 몰이(러시 타임 연장), 즉시 입고, 하루 정산 2배, 유행 힌트 | 하루 6~8회 상한 |
| 전면 광고 | 3일 차부터, 하루 정산 후에만, 최소 3분 간격 | — |
| 광고 제거 | 전면 광고 제거 + 보상형 광고 일부 자동 지급 | ₩3,900 |
| 스타터 팩 | 진열대 1개 + 인테리어 + 코인 | ₩1,200 |
| 가게 확장 팩 | 2층 오락 코너, 가게 앞 평상 등 | ₩2,500~6,500 |
| 시대 챕터 해금 (선택) | 2005~2010 챕터 조기 해금 | ₩2,500 |

- **유료 확률형 아이템 없음** (게임 속 뽑기·카드 팩은 게임 내 코인으로만).
- 광고: **AdMob** (+ 출시 후 미디에이션), 결제: **Unity IAP (Google Play Billing)**.

## 4. 모바일 UX 원칙

- **세로 화면 고정 쿼터뷰**: 가게 내부가 한 화면에 다 보임. 카메라 회전 없음.
- **원터치 조작**: 상품 탭 → 진열대 탭 = 진열. 손님 머리 위 말풍선 탭 = 계산.
- **하루 3~5분, 언제 꺼도 저장**: 오프라인 플레이 가능, 자동 저장.
- **저사양 대응**: 로우폴리, 그림자 최소화, 목표 60fps / 최소 30fps (보급형 폰 기준).
- **APK 용량**: 초기 다운로드 150MB 이하 목표 (큰 리소스는 Play Asset Delivery).

## 5. 기술 스펙

| 항목 | 선택 |
|---|---|
| 엔진 | Unity 6 LTS, URP(모바일 설정) |
| 빌드 | AAB(App Bundle), IL2CPP, ARM64 |
| Target API | 출시 시점 Google Play 요구 최신 API 레벨 (Play Console 정책 재확인) |
| 최소 Android | Android 8.0 (API 26) 정도부터 (보급형 커버) |
| 광고 | Google Mobile Ads (AdMob) Unity 플러그인 |
| 결제 | Unity IAP |
| 분석 | Firebase Analytics + Crashlytics |
| 원격 밸런스 | Firebase Remote Config (유행 확률, 광고 빈도, 가격) |
| 저장 | 로컬 JSON 저장 (+ 나중에 Google Play Games 클라우드 저장) |
| 데이터 | 상품·손님·유행·시대는 ScriptableObject / CSV로 관리 → 코드 수정 없이 콘텐츠 추가 |

**개발 환경 참고:** 이 클라우드 세션에선 Unity 에디터를 실행할 수 없음. Claude가 **C# 스크립트·데이터·프로젝트 구조를 저장소에 작성** → 사용자가 PC의 Unity Hub에서 열어 실행·빌드하는 방식.

## 6. 일정 (약 4~5개월)

| 기간 | 목표 | 체크 |
|---|---|---|
| 1~2주 | **코어 루프 프로토타입** (그레이박스): 매입 → 진열 → 손님 → 계산 → 정산 | 지인 5명이 "하루 더" 누르는지 |
| 3~4주 | 감성 검증: 로우폴리 가게, 상품 20종, ASMR 사운드, 단골 1명 | **숏폼 3~5개 업로드**, 조회·댓글 반응 |
| 5~10주 | MVP 콘텐츠: 1995~2000 챕터, 유행 시스템, 미니게임 2종(딱지·뽑기판), 도감, 꾸미기 | 내부 테스트 |
| 8주~ | **Play Console 등록 + 테스터 모집 시작** | 12명 이상 확보 |
| 11~12주 | 광고·결제·Firebase 연동, 비공개 테스트 **14일** | D1 리텐션, 튜토리얼 완료율 |
| 13~14주 | 프로덕션 액세스 신청 → **사전등록** 오픈 | 숏폼 링크로 사전등록 모으기 |
| 15~18주 | 한국 정식 출시 | 이후 2주 단위 업데이트 |

### MVP 범위
- [ ] 하루 루프 (아침 매입 / 진열 / 하교 러시 / 방과 후 / 정산)
- [ ] 상품 40종 (공통 추억템 70% + 한국 시그니처 30%)
- [ ] 유행 시스템 (주간 붐 + 재고 리스크)
- [ ] 손님 AI (어린이 5타입 + 단골 3명 스토리)
- [ ] 1995~2000 챕터
- [ ] 미니게임 2종 (딱지치기, 번호 뽑기판)
- [ ] 도감 (아이템 설명 — 해외 유저 대비)
- [ ] 가게 꾸미기 기본
- [ ] 보상형/전면 광고, 광고 제거·스타터 팩 IAP
- [ ] 한국어 + 영어

**MVP에서 뺄 것:** 2005년 이후 챕터, 오락기 미니게임, 디지털 펫, 클라우드 저장, 일본어 (→ 업데이트)

## 7. Google Play 출시 체크리스트

| 항목 | 내용 |
|---|---|
| 계정 종류 | **개인 계정**: 바로 시작 가능, 단 **테스터 12명×14일 연속** 필수. 이 테스트를 마치기 전엔 **프로덕션 출시와 사전등록 모두 비활성** / **조직 계정**: 사업자등록 + D-U-N-S 번호(발급 최대 약 30일) 필요, 테스트 의무 면제로 알려짐 |
| 추천 | 사업자등록 계획이 있으면 **지금 바로 D-U-N-S 신청** → 조직 계정. 없으면 개인 계정 + 8주 차부터 테스터 모집 |
| 등록비 | $25 (1회) |
| 개발자 신원 인증 | 계정 생성 시 진행 |
| 콘텐츠 등급 | IARC 설문 (전체이용가~12세 예상, 광고 포함) |
| 타깃 연령 | **13세 이상**으로 설정 권장 (13세 미만 포함 시 가족 정책·광고 제한) |
| 데이터 보안 섹션 | AdMob·Firebase 수집 항목 기재 |
| 개인정보처리방침 | URL 필수 (GitHub Pages로 무료 호스팅 가능) |
| 스토어 등록정보 | 아이콘 512px, 그래픽 이미지 1024×500, 스크린샷 4~8장, 30초 영상(선택) |
| 결제 프로필 | 판매자 계정 연결, 세금 정보 |

### ASO 키워드 (초안)
- 한국어: 문방구, 추억, 레트로, 90년대, 2000년대, 가게 경영, 타이쿤, 시뮬레이션, 힐링, 딱지
- 영어: retro shop, nostalgia, 90s, Y2K, store simulator, shop tycoon, cozy, toy shop, candy shop

## 8. 마케팅 (Android 단독)

1. **숏폼이 주력**: "90년대생만 아는 문방구 아이템" 시리즈, ASMR 클립(포장 뜯기·동전), 단골 성장 장면. 개발 3주 차부터 주 3회.
2. **링크 순서**: 비공개 테스트 모집 → 사전등록 → 출시. 숏폼 고정 댓글에 링크.
3. **커뮤니티**: 추억 게시판·인디 게임 커뮤니티에 개발일지.
4. **스토어 등록정보 실험**: Play Console의 스토어 등록정보 실험으로 아이콘·스크린샷 A/B.
5. **유료 광고는 지표 확인 후**: D1 35%+, D7 12%+ 나오면 소액 테스트.
