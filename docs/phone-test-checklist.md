# 폰 테스트 체크리스트

> 최신 APK: 폰 Download 폴더 `munbanggu-test.apk` → 파일 관리자에서 눌러 업데이트 설치 (진행 상황 유지)
> 표시: ✅ 괜찮음 / ⚠️ 어색함 / ❌ 안 됨 — 어색하거나 안 되는 것만 한 줄로 알려 주세요.
> **테스트용 버튼**: ⚙ 설정 창 아래 "돈 +3만 / 평판 +10 / 날짜 +3일" (테스트 APK에만 있음) → 증축 2·3단계, 직원 여러 명을 빨리 확인할 때 쓰세요.
> **이번 빌드 새로 들어간 것**: 0000번(작업대·깜짝 손님·추억 앨범·고양이 룰렛) → 000번(상인·직원·할머니 스킬) → 00번 → 0번 순서로.

## 0000. 또 뭐가 나올까 (최신 빌드) — 동네 창 맨 위 「또 뭐가 나올까?」
- [ ] **작업대**: 창고에 3개 이상 있는 물건 두 개 넣고 「합치기!」 → 맞는 짝이면 특제 5개 + 「할머니표 특제!」, 틀리면 재료 그대로
- [ ] 처음 힌트 2개(반짝 딱지·꿀 쫀드기)로 만들어 보기 / 레시피 노트에 ???와 힌트가 보이는가 / 만든 특제는 도매상에도 나오고 손님이 찾는가
- [ ] **깜짝 손님** (3일차부터 날마다 40%쯤): 반장 아저씨(대량 주문 2배), TV 리포터(평판·손님↑), 전학생(신상품 하루 일찍), 도깨비 꼬마(비 오는 날, 금화), 옆집 할아버지, 구청장님(평판 75+) — 큰 몸집 + 분홍 대화창
- [ ] **추억 앨범**: 첫 장사·첫 단골·첫 콤보·비 오는 날·증축·대회 등 순간마다 「사진이 꽂혔어요」 → 동네 → 앨범에 그 순간 화면 사진이 보이는가 (16장 다 모으면 마지막 장 「할아버지의 편지」)
- [ ] **고양이 치즈** (5일차~): 문 앞 고양이 → 동네에서 밥 주기 3번 → 가게 식구(러그 위) → 밥 준 다음 날 아침 「선물 룰렛」 → 바퀴가 돌다 멈춘 칸 보상 (동전·직원 아이템·평판·손님 +20%·레시피 힌트·꽝)
- [ ] **재미 질문** "이거 섞으면 뭐가 나올까?"가 궁금해지는가 / 룰렛 돌리는 맛 / 앨범 사진 모으고 싶은가

## 000. 직원·할머니
- [ ] **보따리 상인**: 3일차·6일차…(3일마다) 아침에 상인 대사 → 직원 창에 오늘 물건 3가지(보통·희귀·전설 표시), 하나씩만 살 수 있는가 / 다른 날은 "다음 방문: n일 뒤"
- [ ] **걸음 능력**: 새 직원은 걷는 게 느린가 (1~3) → 물건 채우는 게 느린가 / 운동화·롤러스케이트 달면 빨라지는가
- [ ] **레벨업 포인트**: 레벨업하면 포인트 → 직원 창에서 손 빠르기·걸음·친절·눈썰미에 「+」로 직접 올리는가
- [ ] **특기**: Lv3·6·9에 특기 두 개 중 하나 고르기 (암산왕·지름길 박사·두 팔 가득 등) → 효과가 느껴지는가
- [ ] 진열할 때 매대 앞에서 잠깐 서서 채우는가 (손 빠르기가 높을수록 짧게)
- [ ] **할머니 스킬** (동네 → 할머니 스킬): 날짜·평판이 차면 배울 수 있고, 아직 먼 건 ???로 보이는가
- [ ] 영업 중 아래에 보라색 버튼(할머니 호통! / 번개 계산 / 동네 확성기 / 덤 하나 더) → 눌렀을 때 효과, 하루 횟수 제한
- [ ] **재미 질문** 직원 키우는 맛이 생겼는가 / 상인 오는 날이 기다려지는가 / 할머니 스킬 중 제일 재밌는 것

## 00. 동네 살이 — 아침 하단 보라색 「동네」 버튼 (docs/08)
- [ ] **달력**: 아침에 「오늘의 달력」(요일·날씨·학교 일정·할머니 힌트)이 뜨고, 정산에 「내일: …」 예보가 나오는가
- [ ] 4일차 소풍 전날 간식이 확 팔리는가 / 비 오는 날 밖 놀이(탱탱볼·비눗방울)가 안 팔리고 딱지·카드가 잘 팔리는가 / 일요일 손님이 적은가
- [ ] **동네 대회** (평상 지은 뒤): 창고에 상품이 있으면 「열기」 → 그날 그 물건이 잘 팔리고, 오후쯤 우승자 발표 + 평판 +3
- [ ] **라이벌** (12일차쯤): 「왕문구 할인마트」 개업 소식 → 동네 창에 기세 막대, 상담 딱 맞음·대회·콤보로 기세가 줄어드는가, 0이 되면 문 닫는가
- [ ] **2층 만화방** (만화방 지은 뒤): 동네 → 관리하기 → 만화책 권별 구매, 자리 늘리기, 요금 100/200/300
- [ ] 영업 중 2층 위에 「만화방 n/m명」 말풍선, 창문에 아이들, "만화 보다 배고파요!" 하고 간식 사러 내려오는 아이
- [ ] 수요일 신간 소식 → 그날 사면 손님 ×1.5 / 낙서·몰래 들고 가기 선택 사건이 뜨는가 / 정산에 「2층 만화방 수입」
- [ ] **단골 성장**: 대화창에 「(4학년)」 같은 학년이 보이는가 / 이야기 완성 후 8일쯤 지나 졸업 인사 → 14일 뒤 어른이 되어 큰 몸으로 찾아오는가 (테스트 버튼 날짜 +3일로 빨리)
- [ ] **도감**: 상품·손님·콤보·만화 탭, 못 만난 건 ???와 힌트, 다 채우면 보상
- [ ] **재미 질문** 매일 아침 "오늘은 뭘 준비하지?"가 생겼는가 / 만화방 운영이 할 만한가 / 라이벌이 너무 세거나 약하지 않은가

## 0. 이번 피드백 반영 (2026-11-21 저녁 빌드)
- [ ] **고민 손님**: 하루 5명 정도만 나오는가 (1일차는 2명), 하루 동안 고르게 나오는가
- [ ] **직원이 돌아다님**: 「계산·진열」「진열·계산」 직원이 줄이 생기면 계산대(할머니 옆)로 걸어가 계산, 줄이 비면 창고 상자 → 빈 매대로 걸어가 채우는가
- [ ] 계산 담당은 계산 먼저, 진열 담당은 진열 먼저 하는가 / 둘이 같은 매대로 겹쳐 가지 않는가
- [ ] **진열대 옮기기** (꾸미기 → 「진열대 옮기기」): 진열대 탭 → 바닥 탭하면 옮겨지는가, 「방향 돌리기」로 90°씩 도는가
- [ ] 막히는 자리(문 앞·계산 줄·다른 진열대 앞)는 이유와 함께 거절되는가, 「처음대로」로 되돌려지는가
- [ ] 옮긴 뒤 손님·직원이 진열대를 **돌아서** 다니는가 (뚫고 지나가지 않는가), 옮긴 자리가 껐다 켜도 남는가
- [ ] 옮긴 진열대끼리도 세트 콤보(옆 진열대)가 되는가
- [ ] **동네별 모양**: 아파트는 옆칸이 뒤로 깊은 ㄱ자, 번화가는 첫 옆칸은 얕고 그다음부터 깊은 계단 모양인가
- [ ] **재미 질문** 진열대 배치를 고민하는 게 재미있는가 / 직원이 일하는 모습이 보기 좋은가

## 1. 상담 손님 (가장 중요 — 재미 검증)
- [ ] 계산대로 와서 "할머니, 고민 있어요!" 하는 아이가 보이는가
- [ ] 말풍선 탭 → 고르기 창이 뜨고, 그동안 손님이 멈추는가
- [ ] 예산보다 비싼 상품은 흐리게, 못 누르게 되는가
- [ ] 딱 맞게 골라 주면 "딱 맞아요! … (팁 +○○원)"이 뜨는가
- [ ] 한 번 건넨 상품은 "특징을 알았어요" 알림 → 다음부터 #태그로 보이는가
- [ ] 정산 화면에 "상담 n명: 딱 맞음/괜찮음/아님"과 "동네 평판"이 나오는가
- [ ] **재미 질문 ①** 상담 손님이 오면 "뭘 줄까?" 잠깐이라도 고민되는가
- [ ] **재미 질문 ②** "딱 맞아요!"가 기분 좋은가
- [ ] **재미 질문 ③** 상담을 잘하려고 진열을 바꾸고 싶어지는가

## 2. 돌발 사건 (2일차~)
- [ ] 보라 말풍선 "쉿… 몰래 나가야지" 아이를 문 나가기 전에 탭해서 잡을 수 있는가 (시간 충분?)
- [ ] 외상 선택 창이 뜨고, 다음 날 아침 "외상 장부" 소식이 나오는가
- [ ] 우는 아이(3일차~) 탭 → 친구들이 몰려오는가

## 3. 번호 뽑기판 (3일차~)
- [ ] 도매상에서 번호 뽑기 사서 가게 앞 뽑기판에 걸 수 있는가 (매대엔 안 걸리게 막힘)
- [ ] 아이가 판 앞에서 "뽑기 한 판!" → 탭하면 결과(꽝~1등)가 뜨는가
- [ ] 1등 나오면 동전 터지고 아이들이 더 오는가

## 4. 가게 꾸미기 (업그레이드)
- [ ] 아침 "가게 꾸미기" 버튼 → 목록이 뜨고 사면 바로 가게 모습이 바뀌는가 (간판 전구·선풍기·오락기·진열대)
- [ ] 가격이 너무 싸거나 비싸지 않은가 (며칠 만에 하나 살 수 있는 정도?)
- [ ] 오락기 동전 수입, 영업시간 연장이 체감되는가

## 4-1. 직원 (아침 "직원" 버튼)
- [ ] 지원자 3명 중 고용 → 가게에 앞치마 두른 직원이 서는가 (최대 2명)
- [ ] 직무 바꾸기: 계산원(자동 계산)·진열원(빈 매대 채움)·경비(몰래 나가는 아이 잡음)·상담원(추천 ★ 표시)
- [ ] 교육(돈 내고 레벨업)·아이템 장착이 능력치에 보이는가
- [ ] 정산에서 월급이 빠지는가, 월급이 너무 부담되거나 너무 싸진 않은가
- [ ] **재미 질문** 직원을 키우고 싶어지는가 / 직원이 일을 다 해서 할 게 없어지진 않는가

## 4-2. 진열대 장식 & 콤보 ("꾸미기" → 맨 위 "장식하기")
- [ ] 배치 모드: 진열대마다 "＋ 장식" 표시가 뜨고, 탭하면 장식 창이 열리는가 (겹치면 확대해서 탭)
- [ ] 장식 놓기 → 진열대 위에 사탕 유리병·로봇·트로피 등 모형이 보이는가, 레벨업하면 커지고 금색 받침
- [ ] 코너 콤보: 간식 진열대에 사탕 유리병 → "군것질 코너" 발견 알림 + 이름표 노란색 ★
- [ ] 세트 콤보: 쫀드기·아폴로를 옆 진열대에 → "불량식품 코너" (그 밖의 짝은 직접 찾아보기, 총 15개)
- [ ] 콤보 진열대 물건이 실제로 더 잘 팔리는 느낌인가
- [ ] 치우기/바꾸기 시 절반 환불
- [ ] **재미 질문** 진열 배치를 콤보 때문에 고민하게 되는가

## 4-3. 가게 증축 ("꾸미기" → 맨 위 "가게 증축")
| 단계 | 조건 | 값 | 바뀌는 것 |
|---|---|---|---|
| 1 옆칸 터서 넓히기 | 4일차~ | 12,000원 | 가게가 왼쪽으로 넓어짐, 진열대 +2, 직원 3명, 관리비 300 |
| 2 가게 앞 평상 | 7일차~, 평판 60+ | 25,000원 | 평상, 인내심 +20%, 손님 +10%, 진열대 +1, 직원 4명, 관리비 600 |
| 3 2층 만화방 | 10일차~, 평판 70+ | 45,000원 | 2층 만화방(매일 수입), 손님 +15%, 직원 5명, 관리비 1,000 |
- [ ] 조건이 안 되면 빨간 글씨로 이유가 뜨고 버튼이 "아직 못 지어요"인가
- [ ] 지으면 할머니 대사 + 가게 모습이 바로 바뀌는가 (옆칸 바닥·벽·차양·보도, 평상, 2층)
- [ ] 화면이 넓어진 가게에 맞게 살짝 멀어지는가 (왼쪽 끝이 잘리지 않는지), 확대·이동 잘 되는가
- [ ] **옆칸 동선**: 아이들이 옆칸 진열대로 갈 때·돌아올 때 진열대나 상자를 뚫고 지나가지 않는가
- [ ] 진열원 직원이 옆칸 진열대도 채우러 가는가
- [ ] 옆칸 진열대에도 장식·콤보가 되는가 (옆칸 첫 진열대 ↔ 원래 맨 왼쪽 진열대가 이웃)
- [ ] 정산에 "월세·관리비", 3단계면 "2층 만화방 수입"이 나오는가
- [ ] 앱 껐다 켜도 증축 단계·옆칸 진열이 그대로인가 (진열대 추가 업그레이드와 순서 섞여도)
- [ ] **재미 질문** 증축이 "목표"로 느껴지는가 / 값·조건이 너무 빠르거나 느린가

## 4-4. 상권 이동 (학교 앞 증축 3단계를 다 지으면 증축 카드가 "이사" 안내로 바뀜)
| 동네 | 건물 | 손님 | 잘 팔림 | 직원 | 월세/일 | 이삿값·조건 |
|---|---|---|---|---|---|---|
| 아파트 단지 상가 | 옆칸 1개 붙음, 하늘색 타일·초록 차양 | ×1.25 | 학용품·장난감 | 3명~ | 800 | 60,000원, 평판 70+ |
| 번화가 대로변 | 옆칸 2개 붙음, 검정 체크·파란 차양 | ×1.5 | 장난감·놀이·간식 | 4명~ | 2,000 | 120,000원, 평판 80+ |
- [ ] 테스트 버튼(돈·평판·날짜)으로 학교 앞 3단계까지 지은 뒤 "이사" 버튼 → 확인 창 → 이사가 되는가
- [ ] 이사하면 가게 색·크기가 바로 바뀌는가 (바닥·벽·차양 색, 옆칸이 붙은 넓은 가게)
- [ ] 옆칸 진열대 물건이 창고로 들어오고, 기본 진열대 8칸 진열·장식은 그대로인가
- [ ] 이름표가 겹치거나 빈 자리에 남지 않는가 (예전 옆칸 이름표)
- [ ] 아파트 증축: 옆칸 하나 더 → 아이스크림 냉동고(가게 앞, 파라솔) → 2층 만화방
- [ ] 번화가 증축: 옆칸 하나 더(3칸) → 네온 간판(간판 둘레 분홍·하늘 줄) → 2층 오락실(남색)
- [ ] 옆칸이 2~3개일 때도 아이들·진열원이 진열대를 뚫지 않고 다니는가 (뒷벽 앞 통로로 다님)
- [ ] 가게가 커지면 기본 화면은 멀어지지만 더 크게 확대할 수 있는가
- [ ] 앱 껐다 켜도 동네·색·옆칸·진열이 그대로인가
- [ ] **재미 질문** 이사가 "다음 목표"로 설레는가 / 월세 압박이 적당한가 / 동네마다 다르게 느껴지는가

## 5. 화면·조작
- [ ] 두 손가락 확대/축소, 한 손가락 끌기, 빈 바닥 두 번 탭(원래대로)
- [ ] 1·2·3배속 버튼
- [ ] ⚙ 설정: 배경음/효과음 슬라이더, 소리 끄기가 실제로 되는가
- [ ] 손님이 문으로 드나드는가, 얼굴이 모자에 안 가려지는가
- [ ] 확대했을 때 문 앞 보도 타일이 안 깨지는가
- [ ] 위쪽 UI가 카메라 구멍에 가리지 않는가, 글자 깨짐(네모·빈칸) 없는가
- [ ] 하교 러시 때 끊김(프레임 드랍) 없는가

## 6. 그 밖에
- [ ] 앱 껐다 켜도 날짜·돈·진열·업그레이드가 그대로인가
- [ ] 1일차 튜토리얼 중 상담 손님이 섞여도 헷갈리지 않는가
