# 폰 테스트 체크리스트

> 최신 APK: 폰 Download 폴더 `munbanggu-test.apk` → 파일 관리자에서 눌러 업데이트 설치 (진행 상황 유지)
> 표시: ✅ 괜찮음 / ⚠️ 어색함 / ❌ 안 됨 — 어색하거나 안 되는 것만 한 줄로 알려 주세요.

## 1. 상담 손님 (가장 중요 — 재미 검증)
- [ ] 계산대로 와서 "할머니, 고민 있어요!" 하는 아이가 보이는가
- [ ] 말풍선 탭 → 고르기 창이 뜨고, 그동안 손님이 멈추는가
- [ ] 예산보다 비싼 상품은 흐리게, 못 누르게 되는가
- [ ] 딱 맞게 골라 주면 "딱 맞아요! … (팁 +○○원)"이 뜨는가
- [ ] 한 번 건넨 상품은 "특징을 알았어요" 알림 → 다음부터 #태그로 보이는가
- [ ] 정산 화면에 "상담 n명: 딱 맞음/괜찮음/아님"과 "동네 평판"이 나오는가
- [ ] **재미 질문 ①** 상담 손님이 오면 "뭘 줄까?" 잠깐이라도 고민되는가
- [ ] **재미 질문 ②** "딱 맞아요!"가 기분 좋은가
- [ ] **재미 질문 ③** 상담을 잘하려고 진열을 바꾸고 싶어지는가

## 2. 돌발 사건 (2일차~)
- [ ] 보라 말풍선 "쉿… 몰래 나가야지" 아이를 문 나가기 전에 탭해서 잡을 수 있는가 (시간 충분?)
- [ ] 외상 선택 창이 뜨고, 다음 날 아침 "외상 장부" 소식이 나오는가
- [ ] 우는 아이(3일차~) 탭 → 친구들이 몰려오는가

## 3. 번호 뽑기판 (3일차~)
- [ ] 도매상에서 번호 뽑기 사서 가게 앞 뽑기판에 걸 수 있는가 (매대엔 안 걸리게 막힘)
- [ ] 아이가 판 앞에서 "뽑기 한 판!" → 탭하면 결과(꽝~1등)가 뜨는가
- [ ] 1등 나오면 동전 터지고 아이들이 더 오는가

## 4. 가게 꾸미기 (업그레이드)
- [ ] 아침 "가게 꾸미기" 버튼 → 목록이 뜨고 사면 바로 가게 모습이 바뀌는가 (간판 전구·선풍기·오락기·진열대)
- [ ] 가격이 너무 싸거나 비싸지 않은가 (며칠 만에 하나 살 수 있는 정도?)
- [ ] 오락기 동전 수입, 영업시간 연장이 체감되는가

## 5. 화면·조작
- [ ] 두 손가락 확대/축소, 한 손가락 끌기, 빈 바닥 두 번 탭(원래대로)
- [ ] 1·2·3배속 버튼
- [ ] ⚙ 설정: 배경음/효과음 슬라이더, 소리 끄기가 실제로 되는가
- [ ] 손님이 문으로 드나드는가, 얼굴이 모자에 안 가려지는가
- [ ] 확대했을 때 문 앞 보도 타일이 안 깨지는가
- [ ] 위쪽 UI가 카메라 구멍에 가리지 않는가, 글자 깨짐(네모·빈칸) 없는가
- [ ] 하교 러시 때 끊김(프레임 드랍) 없는가

## 6. 그 밖에
- [ ] 앱 껐다 켜도 날짜·돈·진열·업그레이드가 그대로인가
- [ ] 1일차 튜토리얼 중 상담 손님이 섞여도 헷갈리지 않는가
